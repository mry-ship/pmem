需求来源：用户要求把补全模块规格的通用规则写到九成八。
必须保持：init 覆盖的 pmem-spec 含 `pmem spec complete`、九成八停手、失败条件、配置与环境变量、出参闭集、生成物、按字面抄、禁止「含某某」。
用户说「补全模块规格」或运行 complete（或旧名 fill）时，先跑 complete，再按技能写到九成八。
技能模板只允许 `{generated}` 这一处花括号占位。
入口：pmem init 写出 `.cursor/skills/pmem-spec/SKILL.md`。
