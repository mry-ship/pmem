## 程序设计

`generate/templates.py` 增加 `SPEC_SKILL`，配置模板在 `wiki` 段后增加 `spec.dir`（`.memory/specs`）和 `spec.reminder`（false）。

`generate/integrations.py` 的 `_write_skills` 把 `pmem-spec` 和原有技能一起写到各 Agent 的技能目录，文件头仍是「由 pmem init 生成」。

`init_cmd` 只在 `config.yaml` 不存在时用模板新建。
已存在则不改，因此不会把用户的 `spec.dir` 写回去，也不会补上缺失的 `spec` 段。
缺省值由 `Config.load` 在读取时合并。
