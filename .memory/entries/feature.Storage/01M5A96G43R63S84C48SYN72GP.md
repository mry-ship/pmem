结论：SVN 读提交历史（commits_since，给热度扫描用）时，svn info --xml 的 relative-url 是 URL 编码的（中文、空格变成 %XX），而 svn log -v --xml 里的路径是原始字符。
原先直接用编码后的前缀去匹配，工作副本位于中文或带空格的目录时所有提交都对不上，热度全为 0。现在先用 urllib.parse.unquote 解码（路径里本身的 % 会被编成 %25，解码后仍正确）。
验证：本机没有 svn，用模拟 svn 输出的测试覆盖（tests/vcs/test_vcs.py 的 test_svn_history_decodes_relative_url）；
编码规则来自 svn 的 XML 格式说明，尚未在真实中文路径仓库上实测。
changed_after、dirty_files 用的是本地路径，不受影响。
