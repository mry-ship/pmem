现象：接入 pmem 的项目一轮对话弹约 8 个控制台（约等于 Hook 触发次数）。
pmemw 是 GUI 子系统，本身不建控制台；
若仍弹，多半是 Cursor 用 cmd/pwsh 拉 Hook 且未带 CREATE_NO_WINDOW/windowsHide（论坛与 3.x 仍有报告）。
缓解：hooks 全用 pmemw（含 sessionStart，避免 .cmd）；
用户 settings 设 terminal.integrated.windowsUseConptyDll=true 后重启；
升级 Cursor。
不要指望只换 pmemw 就在所有 Cursor 版本上消掉黑框。
