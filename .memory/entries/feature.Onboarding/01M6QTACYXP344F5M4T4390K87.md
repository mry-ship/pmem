需求：用户要求 pmem init 自动启用项目级 MCP（不要用户级），覆盖 Cursor、Claude Code、Codex。
必须保持：项目配置仍写 .cursor/mcp.json / .mcp.json / .codex/config.toml（禁止提交本机绝对路径 root）；
Cursor 批准写入本机 state.vscdb 的 approvedProjectMcpServers（哈希与 Cursor computeServerConfigHash 一致，配置含未解析的 ${workspaceFolder}）；
Claude 写 ~/.claude.json 对应项目的 enabledMcpjsonServers=['pmem'] 并 hasTrustDialogAccepted；
Codex 写 ~/.codex/config.toml 的 projects 段 trust_level=trusted。
不写用户级 ~/.cursor/mcp.json。
入口：generate/mcp_enable.py，由 integrations.setup_* 在合并 MCP 后调用；doctor 检查 Cursor 项目级批准。
