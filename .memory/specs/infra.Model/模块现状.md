## 模块现状

入口是被其它模块导入，没有独立命令。

配置缺省必须能重做：schema_version 1；project.name 空、type 为 generic、language 为 zh；vcs 为 auto；svn_auto_add 为真；嵌入 backend 为 auto，model、model_path、base_url 为空；gate.mode 为 block，watch 空，ignore 含 md、docs、.memory 和各 Agent 目录；skip_markers 为「跳过记忆」和 skip-memory；resume_markers 为「恢复记忆」和 resume-memory；stop_reminder、analysis_reminder、read_digest、question_review 为真；wiki.auto 为真，wiki.dir 为 .memory/wiki；spec.dir 为 .memory/specs，spec.reminder 为假；server.watchdog 为真，request_timeout 为 120；sync.auto 为 apply，interval_minutes 为 30，full_hours 为 24；write 最短 20、最长 5000、建议 600、每日每议题 5 条、secret_patterns 空；search limit 5、max_per_batch 2、半衰期 90 天、feature_limit 3、inherit_max 2。
record_exempt 缺省按程序设计原文抄全，不要改成「排除测试和文档」这种大意。
analysis_markers 默认含为什么、原因、根因、排查、定位、分析、怎么回事、复现、报错、崩溃、闪退、卡死、不生效、异常、bug、why、debug、investigate。

必须保持：类型和中文名只在本模块定义，检索、Wiki、闸门都从这里导入。
替代关系只由条目的 replaces 计算，撤销了的合并不再隐藏旧记忆。
覆盖草稿保留未知顶层字段。
spec.reminder 缺省关闭；磁盘没写这项的旧项目升级后不弹规格提醒；文件里已经写成 true 的仍提醒。
未实现的需求用 plan 类型，不新增 planned 状态。
没填摘要时标题取去掉类型前缀后的第一句，超 60 字截断加省略号。

一轮例子：合法文件头含 id、module、entity、kind=conclusion、status=active、note_date=2026-10-23，正文超过 120 字且含「1) 」「2) 」，断行后出现换行加两格再加编号。

测试在 tests/core/test_entry.py、test_ids.py、test_config.py、test_textfmt.py。

无。
