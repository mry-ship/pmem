需求来源：深度核对结束提醒，发现两处会漏催。
必须保持：
1) gate.analysis_reminder 缺省 false；DEFAULTS、init 模板、手册示例一致。显式 true 时：排查类查过未写的模块结束催防错类（改过别的模块也不豁免）；非排查整段只查不改不写走较软查阅提醒。
2) 查阅和排查催写记入会话字段 consult_nudged，不写进功能记录用的 nudged，也不写进 spec_nudged。
   同一对话先催过查阅，后来又改了该模块代码却没写功能记录时，仍要发功能记录提醒。
   停止事件日志的 nudged 字段仍把这三类一并记上，供收益报告统计转化。
3) 【pmem】行按“；”分段。“无需记录”只放过同一段里点名的模块的功能记录和规格提醒。“无新结论”点了模块名只放过这些模块的查阅提醒；该段没点名（如“已核对，无新结论”）则本轮查阅提醒全部不发。无新结论不放过功能记录提醒。
4) stop_reminder 缺省仍为 true。
入口：hooks/reminders.py on_stop；hooks/state.py 会话字段 consult_nudged。
