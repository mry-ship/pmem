## 模块现状

入口：`pmem init`、`pmem doctor`、`pmem scan`。
init 成功返回 0。
非法 Agent 名以用法错误退出。

必须保持：已有 config.yaml 不被 init 改写，自定义 spec.dir 仍在。
技能正文含 pmem spec、pmem spec complete、设计留空标记、四类策划词、美术设计、本模块无画面、不要整篇重写、search_memory、新模块、反推循环、合上代码、单独拿走、闭集词表、所有权、一样、相似、依赖规格、入参字段闭集、出参字段闭集、生成物、按字面抄、停手、九成、九成八、失败条件、配置与环境变量、含某某。
规则要求回复开头写【pmem检索】，结尾分段写【pmem查询】和【pmem修改】，前后空一行。
只有 sessionStart 经包装脚本；其余 Cursor Hook 直接调 pmem。
扫描热度路径相对项目目录，项目在仓库子目录时不能对不上。

pmem-spec 技能步骤：先看缺谁；按骨架栏目写程序和现状（含入参出参、失败条件、配置与环境变量、生成物、原文）；策划写代码可见规则并标明已实现行为以这些规则为准；无画面的美术节写一句；然后合上代码做反推循环，直到已实现对外契约能还原到至少九成八；用户说补全模块规格时不走当轮更新的「只改波及段落」。写完把日期改成今天再刷新目录。

一轮例子：空目录 `pmem init --agents cursor` 后存在 .memory/config.yaml、.memory/modules.yaml、.cursor/rules/pmem.mdc、.cursor/skills/pmem-spec/SKILL.md、.cursor/hooks.json、.cursor/mcp.json、.memory/bin/pmem-hook.cmd。
再跑一次 init，config.yaml 内容不变，技能文件被覆盖成当前模板。

懒医生 24 小时后台巡检，状态在本机缓存，Hook 最多一行提示。
测试在 tests/test_cli_flow.py、tests/test_lazy_doctor.py、tests/test_spec.py 的 init 与技能用例、tests/test_integrations.py。

单独拿走时还要带走的依赖规格：
infra.Model（配置缺省，含 spec.reminder 为假）。
feature.Spec（已登记模块时补骨架）。
feature.ModuleCatalog（modules.yaml 已存在则不覆盖）。
feature.Gate（Hook 事件名与包装脚本只包 sessionStart）。
