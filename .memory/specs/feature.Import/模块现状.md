## 模块现状

入口：`pmem import --lancedb <目录> [--catalog <modules.yaml>] [--author imported] [--guess-kind] [--dry-run]`。

必须保持：导入前后源目录文件名不变。
重复导入按 `lancedb:<源id>` 跳过，条目数不增加。
写入顺序按源时间从早到晚，ULID 时间与这次序一致。
含疑似密钥的条目跳过并列出，密钥 id 最多打印 10 个。
`--catalog` 只在 `modules.yaml` 还没有模块时填入参考目录。
默认作者是 `imported`；默认类型是结论。
未安装 `lancedb` 或路径不是目录时返回 2；业务跳过仍返回 0。
没有 MCP 入口。

一轮例子：源库两张业务表加一张不匹配的 catalog 表，其中一条正文含 sk- 密钥。
导入报告读取 2 张表，写入 1 条结论，跳过密钥 1 条；源目录文件名集合不变。
再导一次，跳过已导入 1 条，条目数仍为 1。

可选依赖是 `lancedb>=0.6`。
测试在 `tests/importers/test_lancedb_import.py`。

单独拿走时还要带走的依赖规格：
infra.Model（ULID、断行、类型闭集）。
feature.Storage（落盘）。
feature.ModuleCatalog（参考名单合并，仅当项目还没有模块）。
feature.Tools（密钥规则，含 write.secret_patterns）。
