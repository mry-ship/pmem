排除：不要每次 Hook 或每次 converge finish 都实跑医生；不要让懒医生自动 place 孤儿、改 entries 或 modules.yaml；不要把完整 doctor 报告塞进 Hook 的 agentMessage。
原因：用户只要稍微多几个触发时机，不是改成自动整理记忆库，也不是对话里刷体检全文。自动改库会把「有没有在跑」和「有没有收拾干净」混在一起。
这不是本仓库 `pmem doctor` 的行为；本仓库的自检命令仍然只报告、由人处理。
