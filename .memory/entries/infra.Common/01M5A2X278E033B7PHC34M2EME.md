命令行参数约定（现行）：
1) main.py 只解析参数和分发，具体逻辑在各 *_cmd.py 或 catalog/metrics 里（如 migrate move、split、sync 在 catalog，anchors --rename 在 anchors_cmd）。
   子命令特有参数在 _migrate 里用 getattr 取。
   新增的 *_cmd.py 要登记到对应模块的 paths，否则落到兜底的 infra.Common。
2) “没传”和“传了默认值”要分得清时，argparse 默认值用 None，真正的默认在 run_* 里取：
  - record 的 --supersedes/--anchor/--alias：配 --draft-id 时，不写沿用草稿原值，只写参数名表示清空，写了值就替换。原先默认空列表，覆盖草稿时会清掉替代关系，旧记忆重新变成现行。
  - init 的 --gate/--type、seed 的 --top：为了提示“这个参数没生效”（见 feature.Onboarding / Init、feature.Curation / Seed）。
3) 可跟多个值的参数用 action=extend + nargs=*：--alias 闪退 崩溃，也可重复写；含空格的值要加引号。
风险：脚本里写了 --alias 却不跟值会被当成清空；直接调用 run_init / run_seed 的代码传 None 要能处理（已兜底）。
