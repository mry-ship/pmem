需求来源：用户 2026-10-20 拍板“拒绝”（在允许、只警告、拒绝三者中选了拒绝）。
必须保持：
- record 的 supersedes 里只要有一条属于别的模块（不管它是否现行、是否已归档），整次写入拒绝，错误码 supersede_cross_module；带 draft_id 覆盖也一样。不存在的 id 仍只给警告。
- 错误信息给出两种做法：旧结论在原模块不成立就在原模块写 correction 替代；归错模块就先 pmem migrate move 再替代。
- 因此每日上限豁免不再需要单独判断模块。
- pmem health 新增一节“替代了别的模块的记忆”，列出现行记忆里的跨模块替代（规则之前写下的、或之后被 migrate move 搬出去的）。拒绝原因进 REJECT_CODES。
上线时本仓库仅 1 条现行跨模块替代（Gate/HookLatency 替代 Onboarding 里归错的同议题风险），已用 migrate move 搬到 feature.Gate。
入口：service/record.py 的 _record；metrics/health.py 的 _cross_module_supersedes。
