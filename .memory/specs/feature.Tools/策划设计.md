## 策划设计

Agent 侧只开放检索、写入、确认、图谱和模块名单。
会改历史可见性的操作（归档、退回种子、撤销合并）留在终端，避免模型误触。

覆盖未完成的草稿时，没提到的字段保持原样；模型习惯给可选数组填空列表，所以空列表不能当清空。
真要去掉替代关系走命令行。

疑似密钥一律拒绝写入，不改写成可入库的正文。
同一模块同一议题每天最多 5 条新记忆，防止一轮对话刷屏。
摘要建议 60 字，超过 200 字拒绝。

改了配置不必重启就能在下一次调用生效；只有看门狗开关和超时例外。

已实现行为的策划以代码可见规则为准。
