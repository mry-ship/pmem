更正：终端交接原先只有「明确模块名」或「空=全局检索」两档。
Shell 循环里 `pmem search --module $m` 时 Hook 解析不出模块，会登记空列表，命令行按真实模块名认领失败，同一对话反复给全文，对话内重复率余量主要来自这里。
现在：有 --module/--path 但 resolve 失败时登记通配 `*`（seen.HANDOFF_ANY）；claim_handoff 对指定模块认领「该模块或 *」。空列表仍只给全局检索认领，行为不变。
代价：通配误认对话的窗口与同模块误认类似，后果仍是对方少显示几条正文。
仍成立：认领后不删除交接、120 秒窗口、最多 8 条。
