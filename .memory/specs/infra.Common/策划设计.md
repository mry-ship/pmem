## 策划设计

命令行是人在终端用的入口，和 Agent 用的 MCP 共用业务规则，只是输出形状不同。
默认 JSON 给脚本；brief 给人读，每条一行，避免再经管道按系统代码页解码。

配置或模块名单读不了时，所有普通命令都在开始前用同一行原因退出，退出码 2。
接入、扫描、闸门、服务、自检和对照实验要在配置坏掉时仍能启动或自己报告，所以不做这份预检。

手册、首页和架构说明是队友接入的入口，新命令必须三处一起出现。
模块规格占 v0.6；类型安全与规则化是 v0.7。

已实现行为的策划以代码可见规则为准。
