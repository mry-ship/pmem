需求来源：来源种类和生效日落地后，历史回看和检索展示要跟生效日走，排序不变。

必须保持：
- 带 as_of 时，可见性和替代是否生效都用生效日（valid_from，没有则 note_date）。后继用自己的生效日。
- 不带 as_of 的现行检索不按 valid_from 隐藏记忆本身，包括未来生效日。
- 后继写了未来的 valid_from 时，先不隐藏被替代的那条；没写 valid_from 的替代立即生效。
- 同一口径用于检索、摘要、记忆图、doctor 现行条数、规格预填、断链检测。摘要的替代缓存键含当天日期，过了一天即使文件没改也会重算。
- 检索行始终带 source_kind，未知为 null。没有 verified 时带 unverified=true。
- 来源和未核对不改排序，也不设相关度阈值。
- 多条已经生效的后继同时替代同一条时，时间线和记忆图指向生效最早的那条。议题节点顺序仍按 note_date。

入口：Entry.supersede_in_force；src/pmem/index/store.py 的 superseded。
