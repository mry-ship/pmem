## 模块现状

对本仓库，技能在 `.cursor/skills/pmem-spec/SKILL.md`。
对新项目，`pmem init --agents cursor` 会生成 `.cursor/skills/pmem-spec/SKILL.md`。

技能步骤：先 `pmem spec` 看缺谁；
首稿一次一个模块，写完程序和现状后去掉空标记（spec:empty）；
有画面的补上美术，没有画面的美术节写成「本模块无画面」；
目录里还没有美术设计这一份时补上；
用户说「补全模块规格」或运行 `pmem spec fill` 时，对列出的每个未完成模块按首稿写全；
父模块不写子模块正文；
正文不写「请打开某文件」；
当轮更新只改正波及的段落，新定的策划和美术写入并保留；
写完把 `updated` 改成今天，再运行 `pmem spec index`。
目录的留空列只作提示。
文首事实由命令维护，技能不手改那一段。

测试 `tests/test_spec.py` 的 `test_init_keeps_custom_spec_dir_and_writes_skill`：配置里的 `spec.dir: .memory/custom-specs` 在 init 之后仍在，技能正文含 `pmem spec`、`spec:design-gap`、四类策划、`美术设计`、`本模块无画面`、`不要整篇重写`、`search_memory`、`新模块`。
