## 程序设计

所有权：本模块拥有记忆条目形态、标识符、正文断行和配置缺省。
不拥有落盘、检索、闸门拦截或命令分发。

类型闭集：conclusion、exclusion、correction、risk、decision、feature、plan。
中文名：排除项、风险、更正、决定、结论、功能、规划。
教训是 exclusion、risk、correction、decision、conclusion。
功能记录层是 feature、plan。
坑类是 exclusion、risk、correction。
状态闭集：draft、seed、active、archived。
检索可见：active、seed、draft。
替代仍算数的状态再加 archived。
范围：module（默认，不写进文件）、project。
摘要建议 60 字。

YAML 头必填：id、module、entity、kind、note_date。
缺头、头不是键值对、缺必填、列表字段写成字典，都报错，由存储层转成读失败。
可选字段缺省：status 为 active，revision 为 none，author 为空，supersedes 和 anchors 为空列表。
aliases、summary、verify、applies、verified 有值才写出。
scope 只有 project 才写出。
source.conversation 映射为来源对话。
archived 子键 on、from、by；from 必须是 draft、seed 或 active。
reverted 子键 on、by。
顶层未知键进 extra，重写时原样带回；嵌套字典的未知子键丢弃。
写出时固定先写 id、module、entity、kind、status、supersedes、anchors、revision、author、note_date。
YAML 1.1 会把不加引号的 on 读成布尔，写出时要对日期加引号。

ULID 26 位，字母表 0123456789ABCDEFGHJKMNPQRSTVWXYZ，只认大写。
前 10 位是毫秒时间，后 16 位随机；同一毫秒随机部分加一。
显式传入时间戳时不进本机单调序列。

断行宽度 120。
在句号、叹号、问号、分号后断开。
行内编号断开后缩进两格。
代码围栏和表格行不断。
只并回上一行以句末标点结尾、且括号未闭合、跨度不超过 3 行的断片；作者在括号里自己换的行保留。
碎片短于 6 字且不是编号则并回上一行。
幂等。

配置文件是项目根下 `.memory/config.yaml`。
与缺省深合并后再校验。
节 gate、write、search、server、embedding、wiki、project、sync、spec 必须是键值对。
枚举：vcs 为 auto、git、svn、none；gate.mode 为 off、warn、block；write.default_status 为 active、draft；embedding.backend 为 auto、onnx、ollama、openai、none；sync.auto 为 off、remind、apply。
YAML 把 mode 写成布尔时，true 当 warn，false 当 off；sync.auto 的 true 当 apply，false 当 off。
列表项写成单个字符串时升为一项，不按字符拆。
secret_patterns 必须是正则列表，不升格字符串。
content_max 不能小于 content_min。
项目根是向上找到 `.memory/config.yaml` 的目录。
本机缓存目录：环境变量 PMEM_CACHE_DIR，否则 Windows 用 LOCALAPPDATA/pmem，macOS 用 Library/Caches/pmem，其它用 XDG_CACHE_HOME 或 ~/.cache/pmem。

入口：本模块无独立命令。
记忆文件 YAML 头和 `.memory/config.yaml` 的形状由本模块定义，读写在 Storage 与 Onboarding。

数据形状与闭集词表：
类型闭集、状态闭集、配置枚举见上文。

决定表：
摘要建议 60 字。
断行宽度 120。
并回跨度不超过 3 行。
碎片短于 6 字且不是编号则并回。
ULID 26 位，只认大写。
write.content_min 缺省 20；content_max 缺省 5000；recommend_max 缺省 600。

关键流程：
读入 YAML 与缺省深合并后校验；非法抛 ConfigError。
写出记忆头固定字段顺序；日期键 on 必须加引号。

入参字段闭集：
本模块无独立命令。
记忆文件 YAML 头必填字段：id、module、entity、kind、note_date。
可选字段：status、revision、author、supersedes、anchors、aliases、summary、verify、applies、verified、scope、source、archived、reverted，以及顶层未知键 extra。
配置文件路径是项目根下 `.memory/config.yaml`。

原文（须按字面抄）：
skip_markers 缺省为「跳过记忆」和 skip-memory。
resume_markers 缺省为「恢复记忆」和 resume-memory。
gate.ignore 缺省：`**/*.md`、`docs/**`、`.memory/**`、`.cursor/**`、`.claude/**`、`.codex/**`、`.agents/**`。
gate.record_exempt 缺省：`**/test/**`、`**/tests/**`、`**/__tests__/**`、`**/test_*.*`、`**/*_test.*`、`**/*.test.*`、`**/*.spec.*`、`**/generated/**`、`**/*.generated.*`、`**/*.g.cs`、`**/*_pb2.py`、`**/*.pb.*`、`**/*.json`、`**/*.yaml`、`**/*.yml`、`**/*.toml`、`**/*.ini`、`**/*.cfg`、`**/*.lock`、`**/*.meta`、`**/*.md`、`**/docs/**`。
YAML 写出时 archived 子键 on、from、by 的 on 必须加引号，避免 YAML 1.1 读成布尔。

出参字段闭集：
写出 YAML 头固定先写：id、module、entity、kind、status、supersedes、anchors、revision、author、note_date。
缺头或缺必填时由存储层转成读失败，码见 Storage。
配置校验失败报 ConfigError，文案指出哪一项。
YAML 头可选字段没传则用缺省；传了空列表按空列表写出，与没传不同。

失败条件：
节不是键值对：配置项 <节> 应是键值对，当前为 <现值>
枚举非法：配置项 <键> 只能是 <斜杠分隔允许值>，当前为 <现值>
列表键不是列表：配置项 <键> 应是列表，当前为 <现值>
数值类型错：配置项 <键> 应是整数或数字，当前为 <现值>
数值过小：配置项 <键> 不能小于 <下限>，当前为 <现值>
content_max 小于 content_min：配置项 write.content_max 不能小于 write.content_min
secret_patterns 不是正则列表：配置项 write.secret_patterns 应是正则表达式列表
某项不是有效正则：配置项 write.secret_patterns 里的 <模式> 不是有效的正则：<异常>
YAML 无法解析：.memory/config.yaml 无法解析：<异常>
顶层不是键值对：.memory/config.yaml 的顶层应是键值对，当前为 <类型名>
记忆文件缺头或缺必填：由存储层转成读失败，码见 Storage。

配置与环境变量：
本模块定义全部缺省：schema_version 1；project.name 空、type generic、language zh；vcs auto；svn_auto_add 真；embedding.backend auto，model、model_path、base_url 空。
gate、write、search、wiki、spec、server、sync 缺省见上文与 DEFAULTS。
PMEM_CACHE_DIR：字符串，有则作为本机缓存根。
否则 Windows 用 LOCALAPPDATA/pmem；macOS 用 Library/Caches/pmem；其它用 XDG_CACHE_HOME 或 ~/.cache/pmem。
LOCALAPPDATA、XDG_CACHE_HOME 仅在未设 PMEM_CACHE_DIR 时使用。

生成物：
本模块不写独立文件；记忆文件和 config.yaml 的形状由本模块定义，落盘在 Storage 与 Onboarding。
