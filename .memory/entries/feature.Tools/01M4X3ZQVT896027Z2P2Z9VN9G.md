风险与处理：MCP 服务首次被调用时若立即构造 ONNX 嵌入器，会同步下载约 90 MB 模型，list_modules 这类根本不需要向量的调用也被卡住约 30 秒，Cursor 中可能超时。
已改为首次真正计算向量时才加载模型，模型缓存放在用户缓存目录 models/ 下供所有项目共享，pmem doctor 负责预热。
另外 mcp 库 2.x 把 FastMCP 改名为 MCPServer（mcp.server.mcpserver），旧写法会直接 ModuleNotFoundError，依赖需 mcp>=2.3。
验证：scripts/smoke_mcp.py 以 stdio 启动 pmem serve，模型已缓存时全程约 2.7 秒。
