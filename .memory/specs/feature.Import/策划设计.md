## 策划设计

只读导入参考实现里的 LanceDB 记忆，不改源库。
每条记住源 id，再导一次就跳过。
时间用源创建时刻，保留新旧排序。
类型默认全部当结论；按正文猜类型不可靠，所以不默认打开。
疑似密钥直接丢掉，不改写成可入库的样子。
参考模块目录只用来填空项目，不覆盖已经划好的模块；参考目录没有代码路径，路径要另行补。

导入作者可以统一，因此不按「作者 + 模块 + 时间窗」去并批；每条自成一批是有意的。

已实现行为的策划以代码可见规则为准。

<!-- spec:design-gap -->
未在代码或资源中出现、扫代码也补不回来的完整策划稿：尚未写入。
其它记忆系统的导入方式尚未写入。
