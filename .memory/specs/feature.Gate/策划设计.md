## 策划设计

规格提醒：某一轮改了某个模块的行为，这一轮结束前更新那个目录里改到的那一份，不整篇重写。
回合结束时，若该模块算「改了行为、该写功能记录」，而对应的 `.memory/specs/<模块>/` 里这一轮还没写过，就提醒一次。
声明了「无需记录」、只改了免记录文件、或规格文件已经写过的，不提醒。
每个模块只提醒一次。

写规格文件本身不是业务改动，不因此再要求写一条功能记录。
提醒要求把这一轮新定的策划和美术写入规格并保留；
没有画面的，美术节写「本模块无画面」；
目录里还没有 `美术设计.md` 时补上这一份。

规格提醒默认关闭。`spec.reminder` 设为 true 才提醒；闸门是 `off` 时也不提醒。
