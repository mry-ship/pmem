需求来源：用户 2026-10-20 同意过期核对按写入时版本号补查合并进来的旧提交。
必须保持：VCS.commits_after(revision, paths) 返回当前 HEAD 有、revision 没有的提交（文件 → [(提交号, 提交时刻)]），revision 不存在或不支持时返回空；
file_in_commit(commit, rel) 取某次提交里的文件，取不到返回 None。
revision 传的是 revision() 返回值去掉 "git:" 前缀。
Git 实现用 git log <rev>..HEAD --name-only --relative，路径按 path_batches 分批；基类和 SVN 返回空。
不要与已删除的旧接口 file_at(rel, 日期) 混淆。
