## 程序设计

`core/config.py` 的 `DEFAULTS` 增加 `spec: { dir: .memory/specs, reminder: true }`。
`Config.__init__` 要求 `spec` 和 `gate`、`wiki` 一样是键值对；
`Config.load` 先与 `DEFAULTS` 合并再校验。
因此磁盘上没有 `spec` 段的旧文件，读出来仍有这两项。
只写了 `spec.dir` 时，`reminder` 仍取默认 true。

`spec` 被写成非键值对（例如 `spec: false`）时，加载报 `ConfigError`。
