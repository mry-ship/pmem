用户要求（2026-10-21）：正文硬上限改为 5000 字，init 生成的配置和技能要与默认值一致。
必须保持：templates.py 生成的 config.yaml 里 write.content_max 为 5000；
pmem-compact 技能里“一条放不下时按子议题拆成 2～3 条”的阈值写 5000 字，与 content_max 一致，否则 Agent 会按旧阈值过早拆分。
适用：新接入项目；已接入项目 config.yaml 已存在时 init 不覆盖，需手动改 content_max；技能文件重跑 pmem init 会被覆盖为新模板。
入口：generate/templates.py 的 config 模板和 pmem-compact 技能模板。
