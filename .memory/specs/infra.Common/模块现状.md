## 模块现状

用户可见的入口：

- README「记忆」表：看模块现在是什么样，指向 `.memory/specs/<模块>/`，并说明说「补全模块规格」、用 `pmem spec fill` 先铺骨架。
- README 命令速查：`pmem spec`，含 `fill`。
- `docs/pmem-guide.html`：命令行 `pmem spec [init|index|fill] [--check]`，说明无画面的美术节写「本模块无画面」，目录留空列只作提示，配置示例里有 `spec.dir` 和 `spec.reminder`。init 和同步写入新模块时也补骨架。
- `docs/architecture.md`：`generate` 包含 `spec`，命令分发表含 `spec`。
- `docs/superpowers/specs/2026-10-14-pmem-design.md` 第 11 节有 `pmem spec` 一行。

实现和必须保持的行为在 feature.Spec，不在本模块重复一份。
