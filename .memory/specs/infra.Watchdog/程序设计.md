## 程序设计

`server/watchdog.py` 是 Cursor 连着的轻量进程。
真正的 MCP 跑在 `pmem serve --worker` 子进程里。
本文件不导入 mcp 和服务层。

`server/app.py` 的 `serve()` 决定走看门狗还是直接跑服务。
带 `--worker`，或配置关闭看门狗时，本进程直接 `build_server().run("stdio")`。
否则用当前解释器执行 `-m pmem.cli.main serve --worker`，并带上已解析的根目录；不依赖 PATH 里的 `pmem`。
配置读失败时看门狗仍开启，超时用 120 秒。

协议是一行一个 JSON。
`initialize` 整包缓存；子进程死后用内部 id `pmem-watchdog-init` 代发握手，响不应回给客户端，再补发 `notifications/initialized`。
握手完成前到的消息先排队。
客户端取消的请求从计时表拿掉。
进行中的请求在重启时回 JSON-RPC 错误码 -32603，文案见原文。

子进程退出、单次请求超过当前超时、或 `pmem` 包内 `.py` 修改时间变了（空闲时才换）就换新子进程。
超时每次放宽一倍，最多 8 倍；任一成功响应后恢复原值。
连续失败按 0、1、2、5、10、30 秒退避；活过 60 秒再挂则清零。
退避期间的请求立即回错，并提示用终端检索。
代码更新不走退避。
客户端 stdin 读到结束就关掉子进程，返回 0。

日志按 UTF-8 字节写到 stderr，前缀 `[pmem 看门狗]`。
Windows 下子进程带 `CREATE_NO_WINDOW`。
重启记本机事件 `server_restart`，种类为崩溃、超时或重载。

`cli/main.py` 登记 `serve` 和隐藏参数 `--worker`；看门狗跑完后命令行固定返回 0。
没有单独的 `serve_cmd.py`。

所有权：MCP 工具实现在 Tools；重启事件写入 Metrics。
本模块拥有 stdio 行转发、超时加倍、退避、内部握手和代码热重载。

注入错误的 JSON-RPC 码是 -32603。
内部握手 id 是 pmem-watchdog-init，这条响应不回给客户端。

入口：`pmem serve [--root] [--worker]`。

数据形状与闭集词表：
stdio 一行一个 JSON-RPC 对象。
重启种类闭集：崩溃、超时、重载。

决定表：
配置读失败时超时仍用 120 秒。
超时每次放宽一倍，最多 8 倍；任一成功响应后恢复原值。
连续失败退避：0、1、2、5、10、30 秒。
活过 60 秒再挂则清零失败计数。
代码更新不走退避。

关键流程：
未带 `--worker` 且 watchdog 为真时拉起子进程。
initialize 整包缓存；子进程死后内部握手再补发 initialized。
进行中非 initialize 请求在重启时回 -32603。
客户端 stdin 结束则关掉子进程，返回 0。

入参字段闭集：
`pmem serve`：`--root` 缺省空，解析顺序与 MCP 相同。
`--worker` 为隐藏标志，缺省假；为真时本进程直接跑 MCP。
配置键 server.watchdog 为假时也不走看门狗。
serve 不做配置预检。

原文（须按字面抄）：
内部握手 id 原文 pmem-watchdog-init。
JSON-RPC 错误码 -32603。
进行中请求错误全文：pmem 记忆服务<原因>，正在自动重启，请重试这次调用。
日志前缀 `[pmem 看门狗]`。
重启事件名 server_restart，种类崩溃、超时、重载。
子进程命令是当前解释器加 `-m pmem.cli.main serve --worker`。

出参字段闭集：
stdio 一行一个 JSON-RPC 对象。
进行中请求在重启时错误码 -32603。
客户端 stdin 结束返回 0。
内部握手响应不回给客户端。
进行中请求在重启时出现 error 对象，码 -32603；initialize 不回这条错误。

失败条件：
子进程崩溃或超时：对进行中非 initialize 请求回 -32603，文案见原文。
配置 server.watchdog 为假或带 `--worker`：不走看门狗，本进程直接跑 MCP。
客户端 stdin 结束：退出码 0。

配置与环境变量：
server.watchdog：布尔，缺省真。
server.request_timeout：秒，缺省 120，下限 1。
本模块不读其它环境变量。

生成物：
本模块不写项目文件。
重启记本机事件 server_restart。
日志写到 stderr，前缀 `[pmem 看门狗]`。
