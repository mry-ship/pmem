## 策划设计

一条记忆一个可提交的 Markdown 文件，按模块分目录。
已经进版本库的记忆不能靠草稿 id 原地改正文，避免历史丢失；要改就新写一条并声明替代。
无版本库的目录始终允许覆盖。

过期判定按秒，不按天。
未纳入版本库的文件不报改动，宁可漏报，也不把编辑器误碰的修改时间当成代码改过。
版本库命令失败时当成查不出，而不是当成「没有改动」或「可以覆盖」。

SVN 下未纳入的文件搬家后仍保持未纳入，不自动加入版本库。

已实现行为的策划以代码可见规则为准。

未在代码或资源中出现、扫代码也补不回来的完整策划稿：尚未写入。
多版本库并存、记忆文件备份策略尚未写入。
