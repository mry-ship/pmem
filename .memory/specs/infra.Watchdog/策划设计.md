## 策划设计

MCP 是 Cursor 用标准输入输出拉起的常驻进程，崩了或卡死后客户端不会自动重连。
所以默认在前面加一层看门狗：工具暂时失败，但连接还在，随后自动恢复。

超时按 120 秒起，慢任务可以逐步放宽到 8 倍；成功一次就收回去。
看门狗分不清「慢」和「卡死」，只按超时切。
连续起不来就退避，并告诉 Agent 改用终端检索，不要空等。

改了或升级了 pmem 代码，空闲时自动换子进程，不必每次手动重启。
从没有看门狗的旧版升级后，第一次仍要在 Cursor 里重启一次 MCP。
Cursor 已经把该服务标成出错（例如启动时找不到 pmem）的情况，看门狗管不到。

已实现行为的策划以代码可见规则为准。
