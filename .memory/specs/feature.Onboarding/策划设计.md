## 策划设计

规格正文由技能写，不由目录扫描生成。
`pmem init` 要带上 `pmem-spec` 技能。
模块已经登记时，init 补上还没有的四份骨架，并在下一步写明对 Agent 说「补全模块规格」。
第一次接入时名单还是空的，骨架要等划分模块之后才写得出来。
技能必须写明：首稿的策划只记代码里看得到的数值、边界、表现、规则，其余保留 `spec:design-gap`；
有画面时美术同样只写看得到的风格、布局、状态、动效和资源规格，没有画面就写「本模块无画面」；
当轮更新不整篇重写；
整段由 AI 新做的模块当轮写全策划和已定的美术；
写之前 `search_memory`。
写进规格的句子是模块现在的设计，不写「这一轮只新增」这类过程说明；
还没写入的部分标明「尚未写入」。

已有项目的 `config.yaml` 不被 init 覆盖，里面的 `spec.dir` 保持原值。
