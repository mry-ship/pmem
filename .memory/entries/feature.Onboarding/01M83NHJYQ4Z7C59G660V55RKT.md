适用：pmem-art / 出图闭环（与 pmem 本体 Hooks 闪框不是同一层）。

曾以为 GenerateImage 的 art hook 改成 pyw 就够。
不够：出图还会经 Shell 跑 python/python3 的 converge 或 image_gen，控制台解释器照样弹；
若 pmem 闸门 preTool 还匹配 Shell，每条再闪一次。

必须同时：
1) Windows 合并 stubs 时去掉 pmem preTool 的 Shell 匹配；闸门仍拦 Write/Edit/MCP。
2) CLI 用 pyw -3 -u（或 pmem_artw），禁止 python/python3。
   源码 skill 可留 python3 给 Mac；
   install/ensure_cursor_stubs 在 Windows 整包改写技能、commands、规则和手册；
   运行时 followup 再改写一遍。
3) Windows preToolUse matcher=Shell 用轻量 art_shell_hook.py（约 90ms）把 python/python3/py -3 改成 pyw -3 -u。
   不要用冷启动的 pmem_art.py 当 hook。

排除：只改 hooks，或只在规则里口头禁止 python3。同一仓 Mac/Win 生成物不同，换机需重跑 stubs。改完必须重开 Art 的 Cursor 窗口；hooks 日志里 Shell command 应为 pyw。

合并自 4 条记忆。
