需求来源：用户（2026-10-22）要求新模块自动进入模块目录，尽量短时间内发现。
必须保持：
- Gate._mark_edited：文件不属于任何模块、是代码文件（core/codefiles.is_code_file）、闸门要看（_watched）、不在 third_party/ignored 时，调 core.autosync 拉起后台 pmem sync --auto edit。
  编辑工具和终端命令事后比对都经过这里。
- session 事件不再是空操作：Gate.on_session 按 sync.interval_minutes 节流拉起 session 扫描。
- on_post_tool 在 error_notice 之外附上 autosync.take_notice（每次结果只给一次），要 Agent 转告用户新登记的模块和 rename 办法。
- Hook 里只做毫秒级判断和 Popen（Windows 用 DETACHED_PROCESS，能脱离作业对象就脱离）；不导入 catalog/yaml。
- sync.auto: off 或环境变量 PMEM_NO_AUTOSYNC 时完全不触发。
风险：未在真实 Cursor 里验证 Hook 结束后后台进程是否被一起结束（测试里直接拉起能跑完）。
