## 策划设计

接入一次就要能开始用：配置、模块名单、规则、技能、Hook、MCP 都落到对应 Agent 的目录。
已有项目再跑接入，不能冲掉人改过的配置和名单，但规则和技能要跟上当前版本。
别人的 Hook 和 MCP 项必须保留。

规格正文由技能按代码写，不由扫描生成。
扫描只给划分模块用的目录和热度。
自检只报告，不改文件；有错误才失败，警告仍返回成功，方便日常跑。

项目类型只影响大类预设：游戏偏玩法与系统，应用偏功能与平台，后端偏领域与接口，其它用功能与技术底座。
规格回合提醒默认关，接入时可以问一次；没有终端的自动流程保持关。

已实现行为的策划以代码可见规则为准。
