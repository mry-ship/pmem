结论：SVN 也提供未提交文件清单（dirty_files），供闸门做命令执行前后的快照比对，Git 和 SVN 行为一致。

做法：在仓库根目录跑 svn status --ignore-externals --xml，取修改、新增、删除、缺失、冲突和未纳入版本的条目；未纳入版本的目录展开成其中的文件（svn status 只报目录本身，不展开会漏掉新建目录里的文件）；路径统一转为相对仓库根的正斜杠形式。svn 命令失败时返回 None，调用方据此跳过比对。

影响范围：仅闸门的事后比对使用；外部引用（externals）不计入。风险：大工作副本上 svn status 可能超过 1 秒，会触发闸门的 24 小时快照暂停。
