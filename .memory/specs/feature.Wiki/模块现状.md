## 模块现状

入口：`pmem wiki [--out 目录]`。
不传 `--out` 时用配置 `wiki.dir`，默认 `.memory/wiki`。
成功打印「共 N 页（更新 X、删除 Y）」并返回 0。
有手写同名页未覆盖时列出最多 10 个名字并返回 1。
`--out` 指向已有文件、或配置目录在项目外、或不在 pmem 项目中，返回 2。
非法模块名只警告，仍返回 0。

必须保持：只覆盖自己生成的页面。
页面不能写出输出目录；符号链接不跟随。
配置目录不能指到项目外；自动生成失败不影响已经写入的记忆。
条目显示适用条件；一句话标题用摘要，没有摘要则用正文第一句。
需核实的标题加「⚠ 需核实」，索引统计条数；表格里 0 条需核实写成空白，不写数字 0。
上级文案必须写明上级的教训对本模块同样适用。
Wiki 不是可独立重做模块的规格；规格在另一目录，进版本库。

一轮例子：输出目录已有手写 index.md，不以生成标记开头。
`pmem wiki` 不覆盖该文件，列出 skipped，退出码 1；其它带标记的模块页仍更新。

没有 MCP 工具。
测试在 `tests/test_wiki.py`，层级和演化图另有用例。

单独拿走时还要带走的依赖规格：
infra.Model（wiki.dir、wiki.auto、条目形态）。
feature.Retrieval（过期标记与演化图数据）。
feature.Metrics（完整 HTML 图在 map，不在本模块 Markdown 页）。
