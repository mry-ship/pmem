## 策划设计

`pmem sync --apply` 写入模块名单之后，给还没有规格目录的模块补四份骨架。
自动登记真正追加了模块时同样补骨架。
只预览时不写规格。
骨架不是正文。
四份正文要另外对 Agent 说「补全模块规格」，按代码写全。
看不到的策划和美术留空。

不想被自动登记的目录写进 ignored。
手工删掉的模块，下次扫描仍可能加回来。
