需求来源：用户 2026-10-20 要求两轮复查后全部修复。
必须保持：
1) is_committed 返回 True/False/None：Git 和 SVN 命令出错时都是 None（原先 SVN 出错当成“未提交”），draft_id 覆盖按 draft_forbidden 拒绝；
   新建、还没有提交的 Git 仓库算未提交。
   Hook 注入 draft_id 前也只在明确未提交时注入。
2) run_tool：git/svn 不在 PATH、工作目录不存在、超时都返回返回码 127 的结果，由调用方按“查不出”处理，不抛异常。
3) 读记忆文件出错（YAML 写错、缺必填项、列表字段写成字典等）抛 StorageError storage_read，重写失败 storage_write；confirm、归档、migrate move 逐条报告，不抛异常栈。
入口：vcs/base.py run_tool、vcs/git.py 与 vcs/svn.py 的 is_committed、FilesStorage.read / rewrite / _check_draft。
