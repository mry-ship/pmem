## 程序设计

`index/store.py` 的 `MemoryIndex` 以记忆文件为准，在内存里建倒排和可选向量。
`entry_text` 由议题、摘要、正文、验证、适用条件和别名拼成。
刷新默认节流 10 秒；文件时间或大小变了才重读；坏文件记警告并从索引去掉。

排序：相关度乘时效。
有查询且有嵌入器时，相关度是 0.6 语义加 0.4 关键词；否则只用关键词。
时效按半衰期衰减，默认 90 天，公式是 `0.5 ** (天数 / 半衰期)`，再映射到 0.7 到 1.0。
排除项和更正加 0.05；命中议题加 0.15；同文件锚点加 0.3，同目录加 0.1。
同分时新的 ULID 在前。

同一次写入最多保留 2 条在名额内：有对话 id 按对话并批，否则按作者、模块和 90 分钟滑动窗。
超额的相关结果排到其他相关之后、不相关之前，不丢条；名额内保持原排序。

带 `feature_limit` 时分层：教训最多 `limit` 条全文，功能记录和规划另列标题，互不挤占。
不带时（写入找相近记忆）混排。
查子模块时祖先只给教训，分数乘 `0.85 ** 距离`。
本模块名额不被挤占；祖先在 `limit` 之外另给，默认最多再加 2 条，本模块不足时用空位补满。
两边各自保持降权后的次序，只按分数交错合并。
议题过滤只作用于本模块。

`index/embedder.py` 第一次真正读写向量才打开 `vectors.db`。
关键词检索和找相近记忆不建这个文件。
远程嵌入默认只允许本机和官方 OpenAI 地址；其它 https 地址要本机打开 `PMEM_EMBED_ALLOW_REMOTE=1`。
`OPENAI_API_KEY` 只发给官方地址；请求不跟随跳转，超时 60 秒。
地址不合法时不建嵌入器，检索退回关键词。

`index/anchors.py` 按秒核对关联代码是否在写下（或核对）之后改过。
基准取写入时刻和核对时刻的较晚者；记忆文件在写下后 7 天内的第一次提交可以顺延，余量 60 秒。
带函数名则比函数体，否则比文件。
Git 下还会补查写入之后才合入、时间却早于写入的提交，最多 10 个。
按 id 取全文或 `as_of` 检索时不核对。
跨进程缓存 `anchors.json`，状态没变且不超过 600 秒视为新鲜。

`cli/reindex_cmd.py` 删除向量库、引用缓存和锚点缓存，再强制刷新。
`pmem search` 和 `pmem graph` 入口在 `cli/main.py`，服务层在 `service/search.py`。
没有单独的 `search_cmd.py`。

所有权：对话去重登记在 Common 的 seen；可见状态闭集在 Model；MCP 参数和字段提示在 Tools。
本模块拥有分词、同义展开、打分公式、同批降权、分层、祖先合并、嵌入白名单和锚点过期核对。

中文按相邻两字切；英文整词再拆驼峰和下划线。
同义展开词权重 0.8。
BM25 的 idf 是 log(1 + (n-df+0.5)/(df+0.5))，再按批内最大值归一化到 0 到 1。

入口：`pmem search`、`pmem graph`、`pmem reindex`；MCP 检索参数由 Tools 转发到本模块。

数据形状与闭集词表：
entry_text 由议题、摘要、正文、验证、适用条件和别名拼成。
embedder 为无时不得出现 vectors.db。

决定表：
刷新节流 10 秒。
相关度 0.6 语义加 0.4 关键词。
时效公式 `0.5 ** (天数 / 半衰期)`，再映射到 0.7 到 1.0；半衰期缺省 90 天。
排除项和更正加 0.05；命中议题加 0.15；同文件锚点加 0.3，同目录加 0.1。
同批名额内最多 2 条；滑动窗 90 分钟。
祖先分数乘 `0.85 ** 距离`；inherit_max 缺省 2。
同义展开词权重 0.8。
锚点顺延窗 7 天，余量 60 秒；补查旧提交最多 10 个。
anchors.json 新鲜窗 600 秒。
远程嵌入超时 60 秒。

关键流程：
先映射模块再排序。
有嵌入器用混合相关度，否则只用关键词。
分层时教训与功能记录互不挤占。
第一次真正读写向量才建 vectors.db。

入参字段闭集：
`pmem search`：query 可省略；`--module`、`--path`、`--entity` 缺省空；三者与 query、`--id` 至少要有一个。
`--limit` 缺省空，运行时取配置 search.limit 再夹到 1 到 10。
`--as-of` 格式 YYYY-MM-DD，缺省空。
`--full` 为真假，缺省假。
`--id` 可重复，优先于其他条件，最多 10 条。
`--brief` 为真假，缺省假。
`pmem graph`：`--module` 必填；`--entity` 缺省空；`--brief` 缺省假。
`pmem reindex`：只有 `--root`。

原文（须按字面抄）：
JSON 检索结果里 inherited 为真表示来自祖先。
`--brief` 一行一条；不带则 JSON。
`embedder` 为无时不得出现文件 `vectors.db`。
features_hint 原文以「features 是本模块已实现的功能」开头。
seen_hint 原文以「标 seen 的」开头，含「带 full=true」。
applies_hint 原文：带 applies 的记忆只在该前提下成立：先判断当前情况是否满足，不满足就不要套用。
inherited_hint 原文以「标 inherited 的教训来自上级模块」开头。
verify_hint 原文以「stale=true 的记忆写下」开头。
路径未登记 hint：该路径未登记到任何模块；可带 query 全局检索。

出参字段闭集：
search 成功：ok、module、items，可选 features、hints 类字段、similar_modules、module_exists、resolved_from、related、children。
未知模块：ok 为真，module_exists 为假，similar_modules 为相近名列表，不抛错。
graph 模块概览：ok、module、topics、related。
graph 议题：ok、module、entity、timeline、related。
reindex 解析警告返回 1，否则 0。
未知模块时 features 省略；hints 类字段每个对话给一次，seen_hint 每次都给。
embedder 为无时不得出现文件 vectors.db。

失败条件：
未知模块：ok 为真，module_exists 为假，similar_modules 为相近名列表，不抛错。
reindex 有解析警告：退出码 1。
路径未登记：给 hint「该路径未登记到任何模块；可带 query 全局检索。」，不失败。
向量库损坏：从索引去掉坏文件并记警告，检索仍可用关键词。

配置与环境变量：
search.limit 缺省 5，夹到 1 到 10。
search.max_per_batch 缺省 2。
search.recency_half_life_days 缺省 90。
search.feature_limit 缺省 3。
search.inherit_max 缺省 2。
embedding.backend 缺省 auto。
PMEM_EMBED_ALLOW_REMOTE：值为 1 时才允许非本机、非官方 OpenAI 的 https 地址。
OPENAI_API_KEY：只发给官方地址。
缓存目录见 Model。

生成物：
本机向量库 `vectors.db`，仅第一次真正读写向量才建。
锚点缓存 `anchors.json`，新鲜窗 600 秒。
reindex 删除向量库、引用缓存和锚点缓存后再刷新。
