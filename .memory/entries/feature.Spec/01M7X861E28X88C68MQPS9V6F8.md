需求来源：规格闭集核对落地，替代规划 ClosedSetCheck。

必须保持：
- 命令是 pmem spec closed，可选 --module。只读，不写规格文件。
- 自动输出只有一致、可能不一致、无法判断，不出现已确认不一致。
- --check 仍只看程序和现状里的空标记。
- 入参出参必须一行一个字段名。散文或「含某某」是无法判断。
- 路径不在、路径在但符号不在，是可能不一致。路径逃出项目是无法判断。
- 必须保持的行为始终无法判断，只报告原句仍在。行内锚点另查。
- 不读策划，不把 design-gap 报成不一致。
- 模块路径用和登记相同的通配，src/** 能匹配 src 下的文件。
- 规格预填的现行集合等 valid_from 到了再把旧记忆算成已替代。

入口：pmem spec closed；src/pmem/generate/spec_closed.py。
