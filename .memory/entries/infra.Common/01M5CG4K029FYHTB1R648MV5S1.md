决定（2026-10-20，用户拍板）：v0.4 到转正提示、召回审计为止，团队汇总和 RemoteStorage 中心服务（含身份与权限、审计、看板）长期搁置，用户原话“很长时间是没必要做的”。
- 已实现：pmem health 的未登记模块转正提示、召回审计（见 feature.Metrics / ModuleAudit 与设计文档 14.5），Issue #14 已关闭。
- 搁置项保留已定方向，以后重启时不必重新讨论：团队汇总不搭服务，各人把本机统计导出成文件提交到仓库、负责人汇总；
  要解决隐私（不带检索原文、对话 id）、按人分文件避免冲突、口径与单机 report 一致。
  中心服务等文件方案用起来、确认需要实时共享后再设计。
- 不要把这两项当作待办主动推进；确有多人实时共享需求时再重新评估。
仍有效：路线记在设计文档第 14 节和 GitHub Issue，进度以 Issue 为准；不借鉴的方向见 14.4。
