## 程序设计

所有权：本模块拥有首次接入、自检、目录扫描，以及规则、技能、Hook、MCP 模板的写出。
不拥有闸门运行时逻辑、规格正文、模块名单解析。

`pmem init`：root 默认当前目录；type 可省略，按目录猜测 game、app、backend 或 generic；gate 仅首次写入时生效，默认 block；agents 为 auto、all 或逗号列表。
auto 始终含 cursor；有 .claude 或 CLAUDE.md 加 claude；有 .codex 或 AGENTS.md 加 codex。
配置和名单已存在则不覆盖，并提示改文件而不是命令行参数。
技能和规则每次覆盖。
Cursor hooks.json 删除旧 pmem 项后追加新模板，别人的 handler 保留。
MCP 配置只改 pmem 那一项。
CLAUDE.md 和 AGENTS.md 只替换 pmem 标记段落。
Codex 的 pmem 段已存在则不改。
包装脚本 sh 版 LF 可执行；cmd 版 CRLF 纯 ASCII。
首次生成配置时，终端问是否开启规格提醒，输入 y、yes 或「是」才写成 true；没有终端不询问，保持关闭。

技能恰好 6 个：pmem-bootstrap、pmem-compact、pmem-consolidate、pmem-normalize、pmem-seed、pmem-spec。
技能和规则正文若经格式化替换，花括号必须写成双份，否则 init 报键错误。
生成标记写明由 pmem init 生成，要改行为去 config.yaml。

模块已登记时 init 请规格模块补还没有的骨架，并提示说「补全模块规格」。
没有模块时说明规格等划分后再补，不说首稿已写完。

`pmem doctor`：有错误退出 1，仅警告退出 0。
检查配置、模块数量、超深、覆盖率 95%、路径重叠、空壳、现行条数、未提交记忆、可合并组、相近议题、三家 Agent 的 MCP 和 Hook、PATH 里的 pmem、语义模型、近 24 小时 Hook 错误、最近一条 Hook 日志、Windows 非 UTF-8 代码页。
覆盖率达标打勾，否则感叹号。路径重叠打叉。
懒医生：距上次成功静默体检 ≥24 小时，session / prompt / pre-tool / post-tool / edited / stop 在后台拉起 `pmem doctor --quiet`（help 不展示；不预热语义模型）；状态写本机缓存 `last_doctor.json`，不改 entries、modules.yaml。有 ! 或 ✘ 时最多每天往 Hook 塞一行「🩺 记忆医生：…（可 pmem doctor）」，且只在 session 与 post-tool 取出提示（pre-tool / stop / prompt / edited 只抢槽，避免把提示吃掉却不展示）。不把完整体检放进 additional_context / followup。环境变量 `PMEM_NO_LAZY_DOCTOR` 关闭。崩溃子进程不写 last_run。

`pmem scan`：depth 默认 4，必须是正整数。目录不存在返回 2。
热度是近 180 天改动次数，超过 100 个文件的提交不计。
文件少于 3 的目录默认隐藏。
跳过目录闭集：.git、.svn、.hg、node_modules、obj、bin、build、dist、out、.venv、venv、__pycache__、.idea、.vs、.vscode、.cursor、.memory、target、.gradle、.next、.nuxt、coverage、.pytest_cache、.ruff_cache、vendor、Pods、Carthage、DerivedData、TestResults、site-packages；另跳过点开头目录和后缀 .egg-info。
代码扩展名闭集：.cs、.ts、.tsx、.js、.jsx、.mjs、.vue、.svelte、.py、.go、.java、.kt、.kts、.swift、.m、.mm、.c、.cc、.cpp、.h、.hpp、.rs、.rb、.php、.lua、.dart、.scala、.gd、.shader、.hlsl、.sql、.proto。
闸门判断「改到了没登记的目录」共用这一份扩展名和跳过目录。

入口：`pmem init`、`pmem doctor`、`pmem scan`。

数据形状与闭集词表：
项目类型闭集：game、app、backend、generic。
闸门档位闭集：off、warn、block。
agents：auto、all，或逗号列表 cursor、claude、codex。
技能闭集：pmem-bootstrap、pmem-compact、pmem-consolidate、pmem-normalize、pmem-seed、pmem-spec。
doctor 行首标记闭集：✔、!、✘。
跳过目录与代码扩展名闭集见上文。

决定表：
覆盖率目标 95%。
scan 深度缺省 4。
热度窗 180 天；超过 100 个文件的提交不计。
文件少于 3 的目录默认隐藏。
规格提醒只有输入 y、yes 或「是」才写成 true。

关键流程：
init 先写配置和名单（已存在则跳过），再覆盖技能和规则；已登记模块时请 Spec 铺骨架。
doctor 逐项打勾或感叹号，有 ✘ 返回 1。
scan 按深度列出目录和热度。

入参字段闭集：
`pmem init`：`--root` 缺省当前目录；`--type` 可选 game、app、backend、generic，省略则按目录猜；`--gate` 可选 off、warn、block，仅首次写入配置时生效；`--agents` 缺省 auto，也可 all 或逗号列表。
非法 Agent 名以用法错误退出。
`pmem doctor`：对外只有 `--root`；后台静默体检另有隐藏参数 `--quiet`、`--source`。
`pmem scan`：`--root` 缺省当前目录；`--depth` 缺省 4，必须是正整数。
目录不存在返回 2。

原文（须按字面抄）：
生成标记：由 pmem init 生成，重新运行 pmem init 会覆盖；如需调整请改 .memory/config.yaml。
下一步提示固定句：对 Agent 说「补全模块规格」。
规格提醒询问：输入 y、yes 或「是」才把 spec.reminder 写成 true；其它输入或无终端保持 false。
规格提醒开启后：规格提醒已开启。不想要时，把 .memory/config.yaml 里的 spec.reminder 改回 false。
规格提醒保持关闭：规格提醒保持关闭。以后要开，把 .memory/config.yaml 里的 spec.reminder 改成 true。
规格提醒默认：规格提醒默认不提示。要开启的话，把 .memory/config.yaml 里的 spec.reminder 改成 true。
找不到 pmem 的 session 注入全文：[pmem] 本机找不到 pmem 命令：本项目的研发记忆检查和改代码前的闸门都没有生效。请在这次回复里先告诉用户：按项目 README 安装 pmem（需要 uv），装好后重启 Cursor。
其它 Hook 找不到 pmem 时输出 `{"permission":"allow"}`。
doctor 行首标记闭集：✔、!、✘。
doctor 首行：pmem 自检：<项目根>
配置读不出：配置读不出：<ConfigError 文案>
随后固定句：自检中止：先改好 .memory/config.yaml
无模块时缩进行：还没有划分模块：对 Agent 说“按 pmem-bootstrap 技能划分模块”
PATH 失败：PATH 中找不到 pmem，Agent 无法启动服务和 Hook
PATH 成功：PATH 中可以找到 pmem 命令
收尾行三种：自检完成，一切正常；自检完成，有 <N> 项提醒；自检完成，有需要处理的问题

出参字段闭集：
init 成功返回 0；非法 Agent 名用法错误退出。
doctor 有错误退出 1，仅警告退出 0。
scan 目录不存在返回 2；标准输出目录树与热度。
doctor 标准输出每检查一行「  <标记> <文案>」；无此项时该行省略。

失败条件：
非法 Agent 名：argparse 用法错误退出。
scan 目录不存在：退出码 2。
doctor 配置读不出：退出码 1，先打配置读不出再打自检中止。
doctor 有 ✘：退出码 1；只有 ! 或全 ✔：退出码 0。
技能模板花括号未转义：init 报 KeyError，不写出该技能文件。

配置与环境变量：
首次写入读取 gate.mode、project.type、spec.reminder。
doctor 读取整个 config.yaml；embedding.backend 为 none 或 auto 且无 fastembed 时不下载模型。
本模块不读 PMEM_CACHE_DIR；doctor 读 Config.cache_dir 下 hook-errors.log 与 hooks.log。

生成物：
`.memory/config.yaml`、`.memory/modules.yaml` 仅首次写入。
技能目录：`.cursor/skills/pmem-{bootstrap,compact,consolidate,normalize,seed,spec}/SKILL.md`，以及 Claude 对应目录。
规则：`.cursor/rules/pmem.mdc`。
Cursor：`.cursor/hooks.json`、`.cursor/mcp.json`。
包装脚本：`.memory/bin/pmem-hook`（LF 可执行）与 `.memory/bin/pmem-hook.cmd`（CRLF 纯 ASCII）。
已登记模块时请 Spec 铺 `.memory/specs/<模块>/` 骨架。
