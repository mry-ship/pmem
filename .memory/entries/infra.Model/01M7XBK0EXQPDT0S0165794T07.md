排除：只用 date.fromisoformat 判断 valid_from，或把紧凑日期、周日期改写成标准日再存。

Python 3.11 起 fromisoformat 能解析 20260101（2026-01-01）和 2026-W01-5（2026-01-02）。
生效和替代比的是原字符串："20260101" <= "2026-11-21" 为假，这条后继会一直不算生效，as_of 也会把它当成还没到。
改写成标准日再存会把人手写错的日期悄悄改掉。

必须整段是 YYYY-MM-DD，并且 fromisoformat 成功。不存在的日期（如 2026-02-31）同样拒绝。
