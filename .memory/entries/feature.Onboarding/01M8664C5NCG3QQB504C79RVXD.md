必须保持：新项目模板里 spec.reminder 与 spec.read_before_edit 都是 false。
只在还没有 config.yaml 时询问规格提醒。
输入 y、yes 或「是」才把 reminder 写成 true。
直接回车、n、no、「否」、EOF 或没有终端都保持关闭。
read_before_edit 不单独询问，模板里保持 false。
已有 config.yaml 不覆盖。
入口：pmem init 首次写出 .memory/config.yaml。
