## 程序设计

`core/quality.py` 在写入时给出提示，不拦截。
去掉正文开头一层「决定：」或「结论：」（可带不超过 40 字的括注）再判断原因词。
`feature` 和 `plan` 只检查有没有需求来源或必须保持的行为。
其余类型才查缺原因、像变更记录、决定缺取舍。
`conclusion` 和 `correction` 没填 `verify` 时提示补验证方法。
正文超过建议长度才提示超长；合并时若 `supersedes` 命中至少 2 条现行记忆，改用上限而不是建议长度。

`cli/compact_cmd.py` 列出可合并议题，或输出一组全文和写入命令。
分组在 `service/curation.py`：现行记忆按模块和议题名（大小写不敏感）归组，组内按日期和 id 升序。
条数达到门槛才列出，按条数降序。
合并结果不由这条命令写入；Agent 用 `pmem record` 带 `supersedes` 写一条新记忆。
`--undo` 调用 `StatusOps.revert`：合并产物归档并记下已撤销，仍可见的原记忆重新现行。

`cli/anchors_cmd.py` 给没有关联代码的记忆补锚点。
文件索引从 `scan/files.py` 的 `FileIndex` 导入，本文件仍导出同名，避免测试改导入路径。
扫描跳过第三方目录、`com.` 包和注册表排除项。
正文里的唯一文件名、以及「类名.成员」能对上源文件时才收录；同一文件只留一处，带函数名的优先；每条最多 5 个。
`--rename 旧=新` 可写多次，按参数顺序取第一个命中：精确 `路径#符号`，再文件相等，再目录前缀。
默认只预览，`--apply` 才写回；已替代和已归档的记忆也改，保持历史可追溯。

`cli/format_cmd.py` 对已有记忆跑与写入相同的断行。
默认预览，预览第一条整理后的前 8 行；`--apply` 只改正文，YAML 头原样，原子写入。

`cli/seed_cmd.py` 做种子的确定性部分。
`--plan` 按近 180 天改动热度给正式模块排序，已有 10 条以上现行记忆的排后面。
`--accept` / `--reject` 走状态变更；被忽略的参数组合直接报错退出，不改成另一个动作。

`archive`、`terms`、`confirm` 没有独立命令文件，入口在 `cli/main.py`，实现在 `service/status.py` 和 `service/curation.py`。
MCP 不暴露这几条；种子也不能经 MCP 新建。

所有权：状态流转和合并统计的实现挂在 Tools 的服务层；断行在 Model；文件索引在 Onboarding 的 scan。
本模块拥有写作提示词表、compact / anchors / format / seed 的命令契约。

原因词闭集：根因、原因、因为、由于、所以、导致、结论、排除、风险、注意、不要、不能、勿、禁止、决定、边界、坑、前提、证据、实测、验证、否则、因此、为了、目的、口径、差在、区别、澄清、回归、已知、避免、防止、以免，以及 because、root cause、risk、don't、must not。
变更记录开头词：已经、已、新增、修复、改为、调整、重做、实现、完成、落地、删除、补充、更新、优化。
功能记录需求词闭集：需求、要求、用户、产品、策划、设计、必须、保持、不能、不要、不可、约定、规则、为了、以便、目的、期望、应当、应该、只在、仅在，以及 require、must、should、expect。
决定取舍词闭集：原因、因为、由于、为了、目的、避免、防止、以免、否则、排除、而不是、而非、不用、不再、代价、风险、取舍、权衡、考虑到、踩坑、坑，以及 because、instead、trade-off、otherwise。
只对 conclusion 和 correction 要求填写验证方法。

入口：`pmem compact`、`pmem anchors`、`pmem format`、`pmem seed`；archive、terms、confirm 入口在 Common 的命令表，实现在本模块与 Tools 的状态层。

数据形状与闭集词表：
原因词、需求词、取舍词、变更记录开头词闭集见上文。

决定表：
去掉正文开头一层「决定：」或「结论：」时可带不超过 40 字的括注。
合并 supersedes 命中至少 2 条现行记忆时改用上限而不是建议长度。
format 预览第一条整理后的前 8 行。
anchors 每条最多 5 个锚点。
seed --plan 热度窗 180 天；已有 10 条以上现行记忆的排后面。
compact `--min` 缺省 5。

关键流程：
compact 默认列出可合并组；带模块和议题时打出全文和 record 命令，不自己写入。
anchors 和 format 默认预览，`--apply` 才写回。
seed 非法组合直接报错退出，不改成另一个动作。

入参字段闭集：
`pmem compact`：`--module` 缺省空；`--entity` 必须同时给 `--module`，否则返回 2；`--min` 缺省 5；`--undo` 缺省空，值为合并后的 id；`--json` 缺省假。
`pmem anchors`：`--module` 缺省空；`--rename` 可重复，形态为 旧路径=新路径；`--apply` 缺省假。
`pmem format`：`--module` 缺省空；`--apply` 缺省假。
`pmem seed`：ids 可空；`--plan`、`--accept`、`--reject` 互斥动作；`--top` 只配合 `--plan`，缺省 10；`--all` 只配合 `--accept`；`--module` 可过滤；`--json` 缺省假。
给了 id 不能再给 `--module`。
非法组合返回 2，不执行另一个动作。
`pmem archive`：ids 至少一个；`--restore` 缺省假。
`pmem terms`：`--module` 缺省空；`--top` 缺省 300；`--min` 缺省 2。
`pmem confirm`：ids 至少一个。
`pmem record --seed` 把 status 写成 seed。

原文（须按字面抄）：
种子 JSON 带 `status: seed`。
`--brief` 和闸门摘要标「（种子，待确认）」。
format 预览「N 条有过长的行」。

出参字段闭集：
compact 列出组或打出全文加一条带 supersedes 的 record 命令。
`--entity` 无 `--module` 返回 2。
`--undo` 失败：没有 supersedes、已经撤销过、或又被更新记忆替代。
anchors 未知模块或 rename 格式错返回 1。
seed 非法组合返回 2。
archive 只有 missing 或 skipped 为 1。

失败条件：
`--entity` 无 `--module`：退出码 2。
`--undo`：没有 supersedes、已经撤销过、或又被更新记忆替代则失败。
anchors 未知模块或 rename 格式错：退出码 1。
seed 非法组合：退出码 2。
archive 目标 missing 或 skipped：退出码 1。
format 预览不改文件，退出码 0。

配置与环境变量：
write.recommend_max 用于过长行提示，缺省 600。
本模块不读环境变量。

生成物：
`--apply` 时改写已有记忆文件正文或锚点，不新建模块目录。
compact 本身不写合并产物，由后续 `pmem record` 写入。
