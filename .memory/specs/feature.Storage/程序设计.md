## 程序设计

`storage/files.py` 的 `FilesStorage` 一条记忆一个 Markdown 文件，路径是 `.memory/entries/<模块>/<ULID>.md`。
只扫一层模块目录下的 `*.md`；临时文件以 `.tmp` 结尾，不会进索引。
读用 `utf-8-sig`，写用 UTF-8 和 LF。
`find_path` 只接受 26 位大写 ULID，不合法直接当不存在，避免通配符或 `../` 扫到目录外。
遍历时解析失败记入警告并跳过，不抛栈。

`core/fileio.py` 先写 `.{文件名}.{进程号}.tmp` 再 `os.replace`。
Windows 上遇到占用就等 0.05 秒，最多试 5 次。

草稿覆盖看 `VCS.is_committed`，不看工作区脏不脏。
已有提交记录就不能覆盖；无版本库始终可覆盖。
Git 或 SVN 命令出错返回「查不出」，拒绝覆盖，不当成未提交。
作者不同或跨模块也拒绝。
`draft_id` 同时出现在 `supersedes` 里时改成新建，不覆盖。

`vcs/base.py` 定义版本库接口和无版本库实现。
`run_tool` 在命令不在 PATH、目录不存在或超时时返回码 127，不抛异常。
路径参数按总长 8000 字符分批，避免 Windows 命令行过长后被当成「都没改过」。
改动接口精确到 Unix 秒：`changed_since`、`commit_times`、`file_before`。
未提交修改用文件修改时间；已删除用当前时刻；未纳入版本库的文件不报改动。

`vcs/git.py` 额外提供「某次提交之后合入的提交」和「某次提交里的文件」。
`file_before` 用 `git show <提交>:./<路径>`，点斜杠让路径相对项目根。
`--since` 只给日期时补上 `00:00`，避免 git 用当前时刻截断漏掉当天早些时候的提交。
`cheap_dirty_files` 为真，闸门可以频繁快照。

`vcs/svn.py` 对 `svn info` / `svn status` 解析部分输出：有未纳入路径时退出码是 1，其余路径的 XML 仍完整。
已纳入的文件用 `svn mv --parents` 搬迁；未纳入的普通移动，不自动 `svn add`。
`commits_since` 最多取 2000 条日志。
作者不读 svn 配置，走环境变量或系统用户名。

`vcs/detect.py` 按配置 `auto` / `git` / `svn` / `none` 选择适配器；`auto` 从项目根向上找 `.git` 或 `.svn`。
新建记忆且 SVN 开启 `svn_auto_add` 时才 `svn add`；覆盖草稿不加。

所有权：条目如何解析在 Model；谁决定覆盖草稿在 Tools 调用本模块的检查。
本模块拥有路径、原子写、版本库命令和按秒的改动时刻。

入口：本模块无独立命令。
路径与返回码由 Tools、Curation、闸门调用。

数据形状与闭集词表：
记忆路径 `.memory/entries/<模块>/<ULID>.md`。
读失败码 storage_read；写失败码 storage_write；草稿拒绝码 draft_forbidden。
外部命令失败返回码 127。
vcs 选择闭集：auto、git、svn、none。

决定表：
Windows 占用等待 0.05 秒，最多试 5 次。
路径参数按总长 8000 字符分批。
SVN commits_since 最多 2000 条。
只扫一层模块目录下的 `*.md`。

关键流程：
先写临时文件再 os.replace。
草稿覆盖看 VCS.is_committed；查不出则拒绝。
auto 从项目根向上找 .git 或 .svn。

入参字段闭集：
本模块无独立命令。
对外契约是路径与返回码，由 Tools、Curation、闸门调用。
find_path 只接受 26 位大写 ULID。
改动接口名：changed_since、commit_times、file_before。
vcs 选择键：auto、git、svn、none。

原文（须按字面抄）：
记忆路径是 `.memory/entries/<模块>/<ULID>.md`。
读失败码 storage_read。
写失败码 storage_write。
草稿拒绝码 draft_forbidden。
外部命令失败返回码 127。
Git 取历史用 `git show <提交>:./<路径>`，点斜杠让路径相对项目根。

出参字段闭集：
写成功返回写入路径与 overwritten 真假。
读失败码 storage_read，写失败码 storage_write，草稿拒绝码 draft_forbidden。
外部命令失败返回码 127，不抛异常。
is_committed 查不出时拒绝覆盖。

失败条件：
读失败：码 storage_read。
写失败：码 storage_write。
草稿拒绝：码 draft_forbidden。
外部命令失败：进程返回码 127，不抛异常。
is_committed 查不出：拒绝覆盖。

配置与环境变量：
vcs：闭集 auto、git、svn、none，缺省 auto。
svn_auto_add：布尔，缺省真。
本模块不读环境变量；路径由项目根与模块名决定。

生成物：
记忆文件 `.memory/entries/<模块>/<ULID>.md`。
原子写临时文件 `.{文件名}.{进程号}.tmp`，成功后替换，失败删除。
